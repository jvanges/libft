# libft
Libft — My first C library 📚  Reimplementation of standard libc functions (`memset`, `strlen`, `strcpy`, `strdup`...) prefixed with `ft_`, plus extra utility functions (`strsplit`,...) and a bonus linked-list module (`t_list`). Built as `libft.a` via Makefile (`-Wall -Wextra -Werror`). 42 School project — strict Norm compliance, zero memory leaks.
